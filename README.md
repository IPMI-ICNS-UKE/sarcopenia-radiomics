# Code for: Myosteatosis Outperforms Muscle Mass for Clinical Muscle Function

This repository contains the code used in the study:

> *Myosteatosis Outperforms Muscle Mass for Clinical Muscle Function: a Prospective Study across Conventional CT, Spectral CT, and Radiomics.*

The repository provides the complete computational pipeline for preprocessing, imaging feature extraction, feature selection, model development, and statistical analysis.

## Repository structure

| Stage | Purpose |
|---|---|
| `00_data_utilities` | Data organization and preprocessing. |
| `01_data_description` | Dataset characterization utilities. |
| `02_feature_extraction` | Extraction of conventional CT biomarkers, spectral CT biomarkers, handcrafted radiomics, and deep radiomics features. |
| `03_feature_stability` | Feature stability assessment. |
| `04_feature_filtering` | Feature filtering. |
| `05_feature_selection` | Feature selection. |
| `06_modeling` | Machine-learning model development and evaluation. |
| `07_analysis` | Statistical analyses and visualization scripts. |
